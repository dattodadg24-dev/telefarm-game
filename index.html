Hồ Sơ Phát Hành Game (Publisher Kit)

Hướng dẫn đưa game lên Telegram Bot trong 3 phút

1. Góc Nhìn Nhà Phát Hành (Game Design & Monetization)

  • Core Loop Gây Nghiện: Gieo hạt (1 chạm) ➔ Thời tiết ngẫu nhiên ➔ Chế biến sâu (Sữa, Bánh Mì) ➔ Giao đơn hàng NPC lấy Gem.

  • Doanh Thu (Monetization): Bán gói Chó Corgi Thu Hoạch Tự Động bằng Telegram Stars hoặc nạp TON.

2. Cách Đưa File Này Lên Telegram Thật (3 Bước)

  1. Bước 1 (Host HTTPS): Tải file telefarm_tma.html này lên GitHub Pages, Vercel hoặc Cloudflare Pages (hoàn toàn miễn phí, có sẵn HTTPS).
  2. Bước 2 (Tạo Bot với @BotFather): Mở Telegram, chat với @BotFather ➔ Gõ lệnh /newbot để tạo Bot, sau đó gõ /newapp và dán link HTTPS ở Bước 1 vào.
  3. Bước 3 (Chạy Fullscreen): File này đã nhúng sẵn telegram-web-app.js, tự động đọc initDataUnsafe.user.first_name, kích hoạt rung phản hồi HapticFeedback và bung toàn màn hình!
